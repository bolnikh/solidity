# Simple Bank
Concept: A contract that allows users to deposit and withdraw Ether (ETH). Ideal for learning the basics: payable, modifiers, mappings, and events.

# What to implement:

A deposit() function for depositing funds.

A withdraw(uint amount) function for withdrawing funds (with a check that the user has enough funds).

A getBalance() function for viewing the user's balance.

Deposited and Withdrawn events for logging transactions.

# What this will show

Understanding the most basic constructs of Solidity and working with the native token (ETH).
