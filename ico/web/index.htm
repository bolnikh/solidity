This is example how to create ICO - initial coin offering.
We deploy 2 contracts. First contract owner of another contract (ERC20).
During ICO user can buy coin for fixed price.
After ICO first contract can not sell any coin.
If ICO gain enought ether ICO owner can get this ether.
If ICO don't gain enought ether all users can get there ether back.
  • Choose account to use from upper selector.
  • Deploy contracts.
  • During ICO you can buy coins.
  • After ICO owner can get ether from contract or users can get there ether back, depends on if ICO get enought ether.
  • Users will have theire coins.
