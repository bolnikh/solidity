This is example of commit/reveal voting.
Voting has 2 stages: commit - when user submit hash of his vote
and reveal - when user submit real vote data and program check
if this vote correspond previosly commited hash and if don't reject it.
  • Choose account to use from upper selector.
  • Deploy contract.
  • Generate hash and commit it when commit in progress. Use "Refresh contract Data" button to update contract progress.
  • Vote when reveal in progress.
